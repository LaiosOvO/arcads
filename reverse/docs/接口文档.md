## 鉴权与公共参数

> 本节原记载 `sessionid` / `msToken` / `a_bogus` / `{ret,errmsg,log_id,data}` 信封，经核验系其他站点的模板内容，与 Arcads 实证不符，已按静态代码证据更正。

- 后端 base：`newBackend:!0` 的端点走 `https://api.arcads.ai`；未标记的走旧网关 `https://u5wouxsctc.execute-api.eu-west-3.amazonaws.com`（见 `makeEndpoint` 的 URL 拼装逻辑）。
- 鉴权：`Authorization: Bearer <token>`；token 由 `/auth/renew-token`（GET）续期，登录走 `/auth/google-login`、`/auth/apple-login`（POST），`/auth/link-token`（POST）换取，均声明 `responseSchema: { token: string }`。部分端点带 `sendsDeviceId`。
- 媒体读取：`GET /media/cloudfront-cookies` 取 CloudFront 签名 cookie（404 视为未配置）；`socket.io` WebSocket 以 `auth.token` 连 `https://api.arcads.ai`。
- 缓存策略：客户端对 `GET` 且不在 `/admin/`、`/auth/` 下的请求做缓存；`noCache` / `cacheKey` 可覆盖。
- 其他主机：`song.arcads.ai`、`data.arcads.ai`、`mcp.arcads.ai`、`external-api.arcads.ai`、`t.arcads.ai`（追踪）。
